# Data

This project uses a telecom customer churn dataset (file name: `Customer Churn.csv`).

- 7,043 customers and 21 columns
- 1,869 customers churned (26.54%)
- The data has no dates and no transactions

## Is the data included?

No. The data files are not included in this repository, because they contain customer IDs, and it is not confirmed that the data may be public.

To run the notebook, put your own copy of the data file in this folder.
